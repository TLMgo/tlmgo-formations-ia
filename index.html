Formations IA

Série de cours sur les meilleures pratiques du codage assisté par IA avec Cursor IDE et Claude Code.

Capsule 1

Les Rules

≈10 min .cursor/rules/, .claude/rules/, CLAUDE.md, AGENTS.md, format .mdc, migration depuis un CLAUDE.md monolithique. Capsule 2

Les /Commands & Skills

≈10 min /commands, SKILL.md, Agent Skills standard, Custom Modes, approche skills-first. Capsule 3

Les Hooks

≈15 min Intercepteurs déterministes, événements Pre/Post, 4 types (Command, Prompt, HTTP, Agent), compatibilité cross-Cursor/Claude. Capsule 4

Spec-Driven AI Coding

≈20 min Méthodologie SDD, pyramide de spécifications (Projet/Module/Fonctionnalité), notation EARS, workflow en 4 phases. Capsule 5

MCP — Model Context Protocol

≈18 min Protocole ouvert, JSON-RPC, resources/tools/prompts, transport stdio vs HTTP, modèle de sécurité. Capsule 6

Les sous-agents

≈16 min Isolation de contexte, parallélisme, spécialisation, agents intégrés (Explore, Bash, Browser), agents personnalisés. Capsule 7

Choisir un modèle

≈13 min Comparaison tarifaire OpenAI vs Anthropic, critères coût/vitesse/qualité/fiabilité, matrice tâche-modèle.
